# 🎙️ Fonoaudiologia Premium - Landing Page

> 🔗 **Repositório Oficial:** [https://github.com/marcoaugusto76-prog/fonoclar.git](https://github.com/marcoaugusto76-prog/fonoclar.git)

Esta é uma Landing Page moderna e sofisticada desenvolvida para clínicas e profissionais de Fonoaudiologia que buscam uma presença digital de alto impacto. O design foi projetado com foco em 2026, utilizando conceitos de **Bento Grid**, **Glassmorphism** e animações fluidas para transmitir confiança e acolhimento.

## ✨ Características

- **Design Premium 2026**: Estética moderna com gradientes estilo Aurora e transparências sofisticadas.
- **Totalmente Responsivo**: Adaptado para celulares, tablets e desktops.
- **Seção Hero de Impacto**: Focada em conversão com CTAs claros e diretos.
- **Bento Grid de Serviços**: Visualização clara e moderna das áreas de atuação (Linguagem, Voz, Audiologia, etc.).
- **Integração com WhatsApp**: Botão de agendamento rápido via concierge.
- **Estilos Ultra-Rápidos**: Utiliza Tailwind CSS para performance e customização.

## 🚀 Tecnologias Utilizadas

- **HTML5** & **Vite**: Estrutura e gerenciamento de projeto moderno.
- **Tailwind CSS**: Estilização avançada e responsividade.
- **Phosphor Icons**: Biblioteca de ícones elegantes e minimalistas.
- **Google Fonts**: Tipografia selecionada (Outfit) para máxima legibilidade.

## 🛠️ Como Executar o Projeto

Para visualizar o projeto em seu ambiente local como um site real:

1. **Instale as dependências** (caso utilize o ambiente Node):
   ```bash
   npm install
   ```

2. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```
   O site estará disponível em `http://localhost:5173/`.

Alternativamente, você pode abrir o arquivo `index.html` diretamente em seu navegador para uma visualização rápida.

## 📂 Estrutura de Arquivos

- `index.html`: Estrutura principal do site.
- `src/style.css`: Configurações de estilo base e animações CSS.
- `src/main.js`: Lógica de interações da interface (navbar dinâmica).
- `assets/`: Imagens e recursos visuais da clínica.
